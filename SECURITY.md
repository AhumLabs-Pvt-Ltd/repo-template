# Security policy

## Reporting a vulnerability

Do not open a public issue for a security problem.

Report it privately through GitHub: open the repository's **Security** tab and click
**Report a vulnerability**. If that button is not available, open a minimal issue that
says only "security report, please contact me" and a maintainer will reach out.

Include:

- what you found and where (file, commit, or URL)
- steps to reproduce
- what an attacker could do with it

We will acknowledge your report within 5 working days and tell you what we plan to do.
Please give us reasonable time to fix the problem before you disclose it.

## Scope

- Code and configuration in this repository.
- Leaked credentials, or real (non-synthetic) ship, client or crew data. These count as
  security issues. Report them the same way.

## Supported versions

Only the latest commit on `main` is supported.
